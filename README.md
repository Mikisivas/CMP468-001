# CMP 468: Computer Security Projects

Two complete projects, each with a working system, a full report (introduction to conclusion, 2021 to 2026
literature only) and a step-by-step implementation guide.

| Folder | What it is |
|--------|------------|
| `project1-uniguard/` | UniGuard: automated monitoring, backup and recovery for university digital infrastructure. See its README for setup and the demo script. |
| `project2-agropeace/` | AgroPeace: GIS-based early warning and real-time response for farmer-herder conflict. See its README for setup and the demo script. |
| `reports/Report1_UniGuard_Monitoring_Backup_Recovery.docx` | Report for project 1 |
| `reports/Report2_AgroPeace_GIS_Early_Warning.docx` | Report for project 2 |
| `reports/build_report1.py`, `build_report2.py` | Regenerate the reports after editing (`pip install python-docx`, then `python build_report1.py`) |
| `reports/figures/` | Screenshots used in the reports |
| `DEFENCE_PREP.md` | Slide outline, likely defence questions with answers, and a checklist |

Before submitting: open each report in Word, fill in the title page placeholders, right-click the table of
contents and choose **Update Field**, then save as PDF if your department asks for PDF.
